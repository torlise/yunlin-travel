# 雲林古坑甜點輕旅行一日遊網站

依 2026/09/22 雲林古坑一日遊最新行程整理成手機友善的靜態網頁。

## 功能

- 集合倒數計時，目標 2026/09/22 08:30 沙鹿火車站前集合
- 旅遊當日模式，依最新時間自動顯示下一站與導航按鈕
- 行程延誤模式，可切換準時、+15、+30、+60 分並自動改算預計抵達
- 今日出遊天氣，快速顯示氣溫、降雨機率與濕度
- 行程卡片內建導航按鈕，並標示各站預估車程
- 集合、景點、午餐、下午茶地點的 Google Maps 快速連結
- 溫馨提醒：外帶千層蛋糕請自備保冰袋

可直接開啟 `index.html` 預覽。若部署到 GitHub Pages，使用 root 目錄即可。
